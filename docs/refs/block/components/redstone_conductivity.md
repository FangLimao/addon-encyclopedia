# 方块组件 - minecraft:redstone_conductivity

> [!INFO]
> 本文译自[Microsoft Learn](https://learn.microsoft.com/en-us/minecraft/creator/)，按照 CC BY 4.0 协议进行许可

`minecraft:redstone_conductivity`组件将方块设置为具有红石属性。

> [!IMPORTANT]
> 若要在低于 1.21.30 格式版本的方块中启用该组件，需要打开「即将推出的创作者功能」实验性玩法

| minecraft:redstone_conductivity | 组件信息 |
| ----------------------- | -------- |
| 数据类型                | JSON 对象 |
| 默认值                  |          |

## 参数

| 名称 | 类型 | 默认值 | 说明  |
:-----------:|:-----------:|:-----------:|:-----------:
| allows_wire_to_step_down | 布尔值 | true | 设置方块上方的红石粉是否可以向下传递红石信号 |
| redstone_conductor | 布尔值  | false | 设置方块是否可以被红石充能 |
