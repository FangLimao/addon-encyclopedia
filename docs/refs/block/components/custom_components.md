# 物品组件 - minecraft:custom_components

`miencraft:custom_components`组件向方块添加自定义组件。

| minecraft:crafting_table | 组件信息  |
| ------------------------ | --------- |
| 数据类型                 | 数组 |
| 默认值                   |           |

该组件接受一个数组作为参数，数组的每个元素都应该是自定义物品组件的ID。

## 范例
```json
"miencraft:custom_components": [
    "example:custom_component"
]
```
